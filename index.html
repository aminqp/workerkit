Worker: multiplyMatrices Tasks: 6 × 350×350 matrix multiply (~1 s each) Concurrency: 6

            Memory Handles
            
Zero-Copy Memory References (RAM Store)

            

              Producer generates 250k records with
              memoryOnly: true. Main thread receives ONLY a tiny
              __memory_ref__ token (0 dataset bytes serialized to
              main thread). Consumer worker receives
              __memory_ref__ and resolves the dataset transparently
              in RAM.
            

          

          

            Producer: generateMemoryData (memoryOnly: true)
            Consumer: processMemoryData (deleteMemory: true)
            Main Thread Overhead: 0 MB payload transferred
